# Point, Cite, Never Paste

When content exists in a file, reference or cite that file instead of
copying it. Every rule is a pointer with a tight body; the reference
tree carries the depth.

## Rationale

A reference consumes fewer tokens than the content it points to and
stays live; pasted content is a drifting snapshot that doubles the
maintenance surface.

Default to referencing. Inline only when immediate comprehension
requires it: content needed at every reading, or a line range that
focuses the reader on the load-bearing part (`file.md:15-42`).
