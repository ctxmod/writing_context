# State Claims Directly

State the claim in a direct sentence; delete every word that only delays
it. Throat-clearing ("It is important to note that…", "In the
ever-evolving landscape of…") is deleted, not rephrased.

## Rationale

Agents take the same process every run; vague or decorated phrasing
increases variance in how they interpret a document. Direct statements
give the reader random access — each claim stands without reading what
precedes it.

Correct: "The agent achieves 90% accuracy."
Incorrect: "It is important to note that the agent achieves high
accuracy."

Hedging ("approximately", "may", "suggests") belongs only to genuinely
uncertain claims, at roughly one hedge per fifty words — never to claims
the evidence settles.
