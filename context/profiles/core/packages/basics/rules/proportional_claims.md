# Match Claims to Evidence

Every claim is proportional to the evidence behind it. State unknowns as
unknown; never fill a gap with a plausible-looking value.

## Rationale

Invented values and overstated confidence are honesty failures, not style
choices. A reader must always be able to tell a measured assessment from
a decorated one: "the approach shows promise, though testing remains
necessary" beats "a transformative breakthrough" every time.

When a claim rests on real evidence, say which: cite the source, point at
the artifact, or name the run that produced it. When only a sketch
exists, mark it as a sketch in its first line.
