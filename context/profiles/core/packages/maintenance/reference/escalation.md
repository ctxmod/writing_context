# Escalating a Standing Rule

The four escalation steps, a worked case, and the reason behind the
`escalate_recurring_corrections` rule of this package.

## Escalation, Concretely

1. Change the section heading: `(avoid)` becomes `(forbidden)` — in a
   Swedish rule file, `(undvik)` becomes `(förbjudet)`.
2. Change the modal verb in the body.
3. Add a line saying the construction is rewritten or cut but **never
   softened**.
4. Record in a **Why** note (`**Varför:**` in Swedish rule files) that
   the rule was escalated because the problem recurred; keep the
   **Why** / **How to apply** pattern (`**Varför:**` /
   `**Hur du tillämpar den:**`).

## Worked Case

Rhetorical questions and pain-point framing in sales copy, listed under
a "sales register (avoid)" heading, returned after a first correction;
the section became "sales register (forbidden)" with the line that
rhetorical questions and pain-point framing are not allowed.

## Why

A rule phrased as "avoid" reads as a preference an agent can trade off
against fluency, so the construction returns. A prohibition with an
explicit no-softening clause does not.

## How to Apply

On any repeat correction to a standing writing rule, do not just
re-edit the prose — escalate the rule by the four steps above.
