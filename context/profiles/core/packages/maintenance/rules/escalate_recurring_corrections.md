# Escalate a Recurring Correction to a Prohibition

When the same prose problem comes back after it was fixed once, fix the
prose and raise the standing rule's strength — from "avoid" to an
outright prohibition. A correction that recurs is a signal about the
rule's strength, not just about the prose.

Escalation, concretely:

1. Change the section heading: `(avoid)` becomes `(forbidden)` — in a
   Swedish rule file, `(undvik)` becomes `(förbjudet)`.
2. Change the modal verb in the body.
3. Add a line saying the construction is rewritten or cut but **never
   softened**.
4. Record in a **Why** note (`**Varför:**` in Swedish rule files) that
   the rule was escalated because the problem recurred; keep the
   **Why** / **How to apply** pattern (`**Varför:**` /
   `**Hur du tillämpar den:**`).

Worked case: rhetorical questions and pain-point framing in sales copy,
listed under a "sales register (avoid)" heading, returned after a first
correction; the section became "sales register (forbidden)" with the
line that rhetorical questions and pain-point framing are not allowed.

**Why:** a rule phrased as "avoid" reads as a preference an agent can
trade off against fluency, so the construction returns. A prohibition
with an explicit no-softening clause does not.

**How to apply:** on any repeat correction to a standing writing rule,
do not just re-edit the prose — escalate the rule by the four steps
above.
