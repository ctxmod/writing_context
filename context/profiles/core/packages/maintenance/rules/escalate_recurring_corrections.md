# Escalate a Recurring Correction to a Prohibition

When the same prose problem comes back after it was fixed once, fix the
prose and raise the standing rule's strength — from "avoid" to an
outright prohibition whose text says the construction is rewritten or
cut but never softened. A correction that recurs is a signal about the
rule's strength, not just about the prose.

The test on any repeat correction: did the standing rule change, or
only the prose? The four escalation steps, a worked case, and the
reason are in [escalation](../reference/escalation.md).
