# Put Language-Neutral Principles into Every Locale

When a writing corpus keeps parallel rule sets per language (English
and Swedish rules, say), decide for each new principle whether it is
language-neutral or language-specific. A language-neutral principle —
one about what may be claimed, how firmly, with what evidence — goes
into the rule set of every locale, because every corpus is equally
exposed to the failure it prevents. A language-specific idiom or
register rule binds only its own locale.

When it is unclear which case applies, ask: a Swedish idiom or register
problem is Swedish-only; a principle about what may be claimed binds
both corpora.

Placement in shared modules follows the same split: the language-neutral
principle belongs in the base writing doctrine, which every language
profile extends; only the idiom goes into the language module.
