# Local Content Stays Local Until Promoted

Personal context lives in `context.local/`. Nothing under it is copied
into shared context merely by being selected, rendered, or found useful;
promoting local content into shared context is a deliberate, reviewed
operation.

## Rationale

`context.local/` exists so device- and author-specific knowledge can
accumulate without negotiating publication every time. Treating useful
local content as implicitly shared either freezes personal context or
leaks it; the boundary exists so both layers can move at their own pace.

Local content may depend on shared content freely; shared content must
never depend on local content. A shared file cannot become portable
merely because a local override supplies its missing target.
