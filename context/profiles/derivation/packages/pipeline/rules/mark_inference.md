# Mark What You Inferred

Derived context separates what the source says from what the author
concluded. Metadata fields copied from a source without verification are
marked `inferred`; prose that goes beyond the source is marked as
analysis, not summary.

## Rationale

A rendered bibliography never presents an unverifiable detail as
verified: fields listed in a source's `inferred:` list carry an
`(inferred: …)` marker in footnote entries. The same honesty discipline
governs derived prose — a summary maps the source; an analysis argues
from it. Label the rung accordingly, and a reader can always tell which
kind of claim they are looking at.

Unknowns stay unknown: a field you could not verify is either omitted or
listed as inferred — never filled in with a plausible-looking value.
