# Carry the Live Citations in the Example

Shared content teaches citation syntax inside code spans, where
citations are inert; the live forms stand only in this example
package. A live citation whose key resolves to nothing is an error, so
committing live keys into shared content couples every profile to one
citation target — keeping them here demonstrates resolution end to
end, package content citing the package's own source winning at the
first outward scope, while shared packages keep their teaching inert.

## Worked citations

Every suffix names a declared locator of the source: `writing
principles`, `context principles`, `citations and locators`.

Write to inform; let every claim about a produced artifact answer
"how do you know?"
[@writing_context_sources_ctxmod_source_example_example, writing principles].

A reference consumes fewer tokens than the content it points to
[@writing_context_sources_ctxmod_source_example_example, context principles].

Citations serve the reader's check: state what the cited work did or
found, then cite it
[@writing_context_sources_ctxmod_source_example_example, citations and locators].
