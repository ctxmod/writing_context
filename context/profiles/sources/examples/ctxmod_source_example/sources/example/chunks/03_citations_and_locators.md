Citations serve the reader's check: state what the cited work did or
found, then cite it — a bare name-drop asserts nothing. Locators stay
inline at the citation site (`p. 12`, `§3`) while the footnote list
carries one entry per unique cited target, so a work cited forty times
costs one list line. A suffix that matches no declared locator is prose
carried through, not an error; the `#`-specifier form addresses a file
directly.
